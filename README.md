# Todo List

A browser-based todo list for organizing tasks into projects. Create tasks with descriptions, due dates, priorities, and notes, then track completion from a simple project-focused workspace.

## Preview

![Todo List application showing projects and tasks](<screenshot/todo.png>)

## Features

- Create and switch between projects
- Add, edit, and delete tasks
- Set a task description, due date, priority, and notesS
- Mark tasks as complete or incomplete
- Save projects and tasks in browser `localStorage` so they persist between visits

## Getting started

### Requirements

- Node.js and npm

### Install and run

```bash
npm install
npm run dev
```

Open the local URL printed by webpack-dev-server in your browser.

To create a production bundle, run:

```bash
npm run build
```
